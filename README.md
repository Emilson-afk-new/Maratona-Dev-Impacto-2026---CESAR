# Maratona Dev-Impacto 2026 - CESAR

Este repositório é a garagem do nosso sistema, focado em resolver um problema comum da juventude. Nem sempre é fácil organizar os compromissos escolares, perder a data de um trabalho ou não estudar para uma prova porque esqueceu o dia é comum, mas não é normal!
Por isso, pensando nesse problema, nossa equipe desenvolveu uma agenda digital interativa que vai ajudar os alunos a se planejarem melhor.

Equipe: Emilson Filho, José Felipe e Ronald Silva.
